### 💡 About me

Ever since I was a kid, I’ve been curious about how things work. It started with an old Lenovo laptop, Notepad, and Chrome — then tutorials, documentation, and a lot of trial and error. That curiosity became a Computer Science degree at Cagayan State University, where I graduated **Cum Laude** and earned **Best Thesis** for AQRO, a QR-powered reusable container system.

Today I’m a **Junior Developer at Thurston Software Solutions**, building enterprise insurance modules in **ASP.NET Blazor, C# and MSSQL**. I enjoy the overlap between engineering and design: clean architecture, thoughtful interfaces, and software that makes someone’s day easier.

When I’m not coding, I’m usually playing mobile games or watching anime.
